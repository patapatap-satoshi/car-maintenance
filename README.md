# クルマ整備ノート（car-maintenance）

車の消耗品（オイル・タイヤ・バッテリー・各種フィルターなど）の交換履歴を記録し、
**前回交換からの経過** と **次回の交換推奨時期** を自動で表示する Web アプリです。

## 主な機能

- **交換記録**：項目・交換日・走行距離を入力して保存
  - 入力中に「前回交換からの経過（期間・距離）」と「次回交換推奨（日付・距離）」がその場で表示されます
  - **型番・品番**、メーカー・商品名、作業店舗、メモも記録可能
  - 費用は **部品代** と **工賃** に分けて入力し、合計を自動計算して表示
  - 型番などは前回の記録から自動で引き継ぎ、過去の入力から候補表示
- **交換時期の一覧**：項目ごとに以下を自動計算し、「超過 / まもなく / 良好」で色分け
  - 前回交換からの経過（例: `1年2ヶ月（428日）・12,000km 走行`）
  - 交換推奨時期（期間と距離の **早い方**）。距離ベースの到達日は記録から求めた平均走行距離で予測
- **履歴**：項目での絞り込み、型番・メモの検索、編集・削除
- **設定**：複数車両の管理、交換推奨間隔（km / ヶ月）の変更、独自項目の追加
- **バックアップ**：JSON の書き出し・読み込み、CSV 書き出し（Excel 対応。部品代・工賃・合計の列あり）

| 項目 | 距離 | 期間 |

| エンジンオイル | 5,000km | 6ヶ月 |
| オイルフィルター（エレメント） | 10,000km | 12ヶ月 |
| ミッションオイル / ATF・CVTF | 40,000km | 48ヶ月 |
| ブレーキフルード | — | 24ヶ月 |
| クーラント | — | 24ヶ月 |

| バッテリー | — | 36ヶ月 |
| エアフィルター | 30,000km | 24ヶ月 |
| エアコンフィルター | 15,000km | 12ヶ月 |

※ 車種や使い方（ターボ車、短距離走行の多いシビアコンディションなど）で適切な間隔は変わります。取扱説明書に合わせて設定してください。

### 状態の判定

- **超過**：推奨日を過ぎた、または推奨距離を超えた
- **まもなく**：推奨日まで30日以内、または残り距離が間隔の10%（最低500km）以下
- **良好**：上記以外

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。

```sh
npm start   # ローカルサーバーで開く場合（任意）
npm test    # 計算ロジックのテスト
```

GitHub Pages などに置けばスマホからも使えます。データはブラウザ（localStorage）に保存され、
端末ごとに別々になります。機種変更時は「設定 → バックアップ」で JSON を書き出して読み込んでください。

## ファイル構成

```
index.html        画面
css/style.css     スタイル（ダークモード対応）
js/calc.js        日付・距離・推奨時期の計算（DOM 非依存）
js/store.js       データ保存と初期項目
js/app.js         画面制御
tests/            計算ロジックのテスト（node --test）
```
